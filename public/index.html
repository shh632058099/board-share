帮助

按下面步骤操作，就能完成预约、取消、归还和管理。

普通用户最快路线

  1. 打开“单板列表”。
  2. 找到要用的单板，点击“预约”。
  3. 选择开始时间和申请时长。
  4. 用完后进入“我的使用”，点击“归还”。

找空闲时间

  1. 打开“占用时间线”。
  2. 选择开始和结束时间，点击“查看”。
  3. 点击绿色空闲段上的“预约”。
  4. 确认申请信息。

管理员最快路线

  1. 进入“管理”。
  2. 在“管理员配置”里新增管理员。
  3. 在“单板配置”里新增或编辑单板。
  4. 空闲单板可以删除，已删除单板可以恢复。

页面怎么找

单板列表 预约 占用时间线 找空闲段 我的使用 取消/归还 管理 管理员和单板配置

预约单板

1点击“预约”
2选择开始时间
3填写申请时长
4点击“确认申请”

申请时长最小是 0.5 小时，只能按 0.5 小时递增。用途备注建议写清楚，例如“调试 OTA 升级”。

取消预约

只能取消尚未开始的预约。进入“我的使用”，在“我的预约”里点击“取消预约”。取消后，这段时间会重新变为空闲。

归还单板

用完后进入“我的使用”，在“当前占用”里点击“归还”。归还后，单板会重新变成可申请。

请求别人归还

如果单板显示“已超时”，可以在“单板列表”点击“请求归还”。如果系统配置了飞书通知，会尝试发送提醒。

管理员配置

只有管理员能看到“管理”。在“管理员配置”里输入用户 ID 和姓名，点击“新增管理员”。用户 ID 可以从页面顶部姓名后面的括号里复制。

环境变量里的管理员会显示为“配置管理员”，不能在页面删除。系统不允许删除最后一个有效管理员。

常见提示

该时间段已被预约换一个绿色空闲段。
当前用户不是管理员联系管理员添加权限。
只能取消尚未开始的预约已经开始的记录需要归还。
至少保留一个管理员先新增另一个管理员。
